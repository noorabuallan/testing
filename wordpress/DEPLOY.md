# نشر موقع MKN ARABIA على Hostinger (WordPress)

الموقع قالب WordPress اسمه **MKN ARABIA** في `wordpress/mkn-arabia`، بنفس تصميم الموقع الثابت. عند تفعيله أول مرة يُنشئ تلقائيًا:
الصفحات العشر، والمقالات الثلاث، و10 دراسات حالة، و39 رأي عميل، و16 شعارًا (مع صورها في مكتبة الوسائط)، و13 سؤالًا شائعًا، وروابط المقالات `/insights/اسم-المقال/`، وتحويل الروابط القديمة (`services.html` …) إلى الجديدة.

## الطريقة 1 — أرفعه أنا عبر Hostinger API
يحتاج مرة واحدة:
1. hPanel ← الصورة الشخصية ← **API** ← أنشئ مفتاحًا.
2. في إعدادات بيئة العمل (قائمة البيئة أعلى الجلسة ← Edit):
   - **Network access**: اجعلها Full، أو أضف `developers.hostinger.com` و`mknarabia.com`.
   - **Network secrets**: أضف المفتاح باسم `HOSTINGER_API_TOKEN`.
3. جلسة جديدة ← «ارفع الموقع».

ثم يُشغَّل:
```bash
python3 tools/deploy/hostinger_deploy.py --dry-run   # قراءة فقط: يعرض ما سيحدث
python3 tools/deploy/hostinger_deploy.py             # التنفيذ
```
السكربت: يجد الموقع ← يثبّت WordPress بالعربية إن لم يكن مثبتًا ← يرفع القالب ويفعّله ← يفعّل SSL وتحويل HTTPS ← يفتح الموقع لتشغيل الاستيراد ← يمسح الكاش ← يفحص كل الصفحات ونقطة استقبال الطلبات.

## الطريقة 2 — بنفسك في 5 دقائق (بدون API)
1. hPanel ← Websites ← mknarabia.com ← **WordPress** ← تثبيت (اللغة: العربية).
   إن كان في `public_html` ملف `index.html` من الموقع الثابت فاحذفه من File Manager، وإلا سيظهر بدل WordPress.
2. ادخل لوحة WordPress ← المظهر ← القوالب ← إضافة قالب ← **رفع قالب** ← اختر `mkn-arabia.zip` ← تثبيت ← **تفعيل**.
3. افتح الصفحة الرئيسية مرة واحدة (يستغرق أول فتح بضع ثوانٍ لأن المحتوى يُستورد).

## بعد النشر (من لوحة WordPress)
- **إعدادات MKN**: تأكد من رقم واتساب والبريد ورابط الحجز. ضع معرّفات GTM أو GA4 أو Meta Pixel عندما تكون جاهزة.
- **صندوق البريد** `contact@mknarabia.com` يجب أن يكون موجودًا في hPanel ← Emails، لتصل نسخ الطلبات.
- **Google Search Console**: أضف `https://mknarabia.com/wp-sitemap.xml`.
- غيّر كلمة مرور المدير إن ثبّتُّ WordPress بالطريقة 1. الدخول من hPanel ← WordPress ← Admin Panel لا يحتاج كلمة مرور.

## ماذا تعدّل وأين
| تريد تعديل | من القائمة |
|---|---|
| مقال جديد أو تعديل مقال | المقالات (التصنيف القصير، جملة الدعوة، وروابط «اقرأ أيضًا» في صندوق أسفل المحرر) |
| رأي عميل | آراء العملاء (النص، المدينة، الدولة، الشعار، الحالة المرتبطة، الظهور في الرئيسية) |
| دراسة حالة | دراسات الحالة (الصورة، التحدي، دورنا، ما نفذناه، المخرجات، الخدمات والحل المرتبط) |
| شعار عميل | شعارات العملاء (الملف، الخلفية فاتحة أو داكنة أو لون مخصص) |
| سؤال شائع | الأسئلة الشائعة |
| الطلبات الواردة من النموذج | طلبات التواصل (مع زر واتساب للرد، وتصدير CSV) |
| واتساب والبريد والحجز والقياس | إعدادات MKN |
| عنوان ووصف أي صفحة في Google | صندوق «الظهور في Google» داخل الصفحة أو المقال |

الترتيب في كل قائمة يتبع حقل **«الترتيب»** (الأصغر أولًا).

## التحديث إلى 1.1.0 (صفحات الخدمات والأسواق وSEO)
1. لوحة WordPress ← المظهر ← القوالب ← إضافة قالب ← رفع قالب ← `mkn-arabia.zip` ← **استبدال الحالي بالمرفوع**.
2. افتح الصفحة الرئيسية مرة واحدة: تُضاف تلقائيًا 15 صفحة جديدة (8 خدمات، صفحة الأسواق، 6 دول خليجية)، وتُصنّف المقالات، وتُكتب العناوين والأوصاف في AIOSEO حيث كانت فارغة. لا يُحذف ولا يُعدّل أي محتوى عدّلته.
3. **إعدادات MKN ← استيراد المحتوى ← «مزامنة الصفحات المصممة وعناوين Google»** (مرة واحدة): يزيل عناوين ونصوص الموقع القديم (Coming Soon) من الصفحات المصممة — النص القديم يبقى في «المراجعات» — ويكتب عناوين وأوصاف القالب في AIOSEO.
4. All in One SEO ← Sitemaps: تأكد أن الخريطة مفعّلة، ثم افتح `mknarabia.com/sitemap.xml` وتأكد من ظهور الصفحات الجديدة.
5. LiteSpeed Cache ← Purge All.

### ما يحتاج حساباتك (لا يمكن تنفيذه من القالب)
| المهمة | أين |
|---|---|
| إرسال `https://mknarabia.com/sitemap.xml` وفحص الرئيسية وأهم الصفحات بـ URL Inspection ثم «طلب فهرسة» (لإزالة نتيجة Coming Soon القديمة) | Google Search Console |
| إضافة الموقع أو استيراده من Search Console وإرسال الخريطة | Bing Webmaster Tools |
| مسار قياس واحد: إما GTM (`GTM-T9846FTJ`) أو وسم Site Kit لـ GA4 — ليس الاثنين — ثم اختبار في Tag Assistant وDebugView | GTM + Site Kit + GA4 |
| تعليم `generate_lead` كـ Key event (يُرسل الآن فقط بعد قبول الخادم للطلب، ومعه `target_market`) | GA4 ← Events |
| مراجعة ملف النشاط التجاري: العنوان الحقيقي في الأردن أو منطقة خدمة، دون فروع افتراضية في دول الخليج | Google Business Profile |

## تحديث التصميم لاحقًا
التصميم يُولَّد من `tools/site/build.py` (نفس مصدر الموقع الثابت). بعد أي تعديل شغّل:
```bash
python3 tools/site/build.py
```
فيُحدِّث الموقع الثابت وملفات القالب معًا. ثم أعد رفع القالب بالطريقة 1 أو 2. إعادة الرفع لا تمس المحتوى المعدَّل من اللوحة.
