# موقع MKN ARABIA

موقع ثابت (HTML/CSS/JS) باللغة العربية، مبني من **بروفايل الشركة 2026** و**ملحق الأسعار 2026**. لا يحتاج أي مكتبات أو خطوات بناء.

## الصفحات
| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: الملخص التنفيذي، المحاور الأربعة، الأقسام D01–D08، المشكلات التي نعالجها، حلقة النمو، الأعمال المختارة، نماذج التعاون |
| `services.html` | الأقسام الثمانية بخدماتها ومخرجاتها وحدودها |
| `pricing.html` | 24 باقة (تبويبات) و8 حلول متكاملة — بدون أسعار، مع زر "اطلب عرض سعر" لكل باقة |
| `work.html` | 10 حالات أعمال بأرقامها وقراءتها كما في البروفايل |
| `about.html` | المسار، الرؤية والرسالة، القيم الست، التركيز السوقي، القيادة، المنهجية، المسؤوليات، القياس |
| `contact.html` | بيانات التواصل، نموذج يرسل الطلب على واتساب، خطوات البدء، الأسئلة الثمانية |
| `privacy.html` | سياسة الخصوصية وأدوات القياس |
| `utm.html` | أداة داخلية لإنشاء روابط الحملات (غير ظاهرة في القائمة) |

## التتبع (GA4 / GTM / Meta / TikTok / Google Ads)
كل زيارة وطلب مربوط بمصدره عبر UTM. ضع المعرّفات أعلى `assets/js/tracking.js`، والتفاصيل الكاملة في **[TRACKING.md](TRACKING.md)**.

## التعديل
- **رقم واتساب والبريد**: أعلى `assets/js/main.js`.
- **الألوان**: متغيرات `:root` في `assets/css/style.css` (الأسود `#0d1114` والأزرق `#3fb3dc` من البروفايل).
- **الشعار**: `assets/img/logo-white.png` و `logo-dark.png` (من ملفات الهوية الأصلية).
- **صور الأعمال**: `assets/img/work/`.

## التشغيل محلياً
```bash
python3 -m http.server 8000
```

## النشر
يعمل مباشرة على GitHub Pages أو Netlify أو Vercel أو أي استضافة، ويمكن ربطه بالنطاق `mknarabia.com`.
