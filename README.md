# موقع MKN ARABIA

موقع ثابت (HTML/CSS/JS) باللغة العربية، مبني من **بروفايل الشركة 2026** و**ملحق الأسعار 2026**. لا يحتاج أي مكتبات أو خطوات بناء.

## الصفحات
| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: شعارات العملاء، الأعمال المختارة، «ابدأ من نوع نشاطك»، مجالات الخدمة D01–D08، المحاور الأربعة، آراء العملاء، المؤسس، الشعار والبورتريهات، المقالات |
| `services.html` | المشكلات التي نعالجها، ثم مجالات الخدمة الثمانية بخدماتها ومخرجاتها وأعمالها المرتبطة (مع شريط تنقل ثابت) |
| `pricing.html` | نماذج التعاون، 24 باقة (تبويبات) و8 حلول متكاملة — بدون أسعار، مع زر "اطلب عرض سعر" لكل باقة. الرابط `pricing.html#d04` يفتح تبويب القسم مباشرة، و`#x06` يفتح الحل المتكامل |
| `work.html` | فهرس و10 حالات أعمال (بدون أرقام إيرادات)، لكل حالة خدماتها المرتبطة وزر «ناقش مشروعًا مشابهًا» |
| `about.html` | المسار، الرؤية والرسالة، القيم الست، التركيز السوقي، القيادة، المنهجية، المسؤوليات، القياس |
| `contact.html` | بيانات التواصل، نموذج يرسل الطلب على واتساب (مع تحقق عربي من الحقول)، الحجز المضمّن، خطوات البدء، الأسئلة الشائعة |
| `insights.html` + `insights/*.html` | المقالات (3 مقالات عربية) |
| `testimonials.html` | آراء العملاء حسب الدولة (مع شعار العميل عند توفره) |
| `privacy.html` | سياسة الخصوصية وأدوات القياس |
| `utm.html` | أداة داخلية لإنشاء روابط الحملات (غير ظاهرة في القائمة) |

## التتبع (GA4 / GTM / Meta / TikTok / Google Ads)
كل زيارة وطلب مربوط بمصدره عبر UTM. ضع المعرّفات أعلى `assets/js/tracking.js`، والتفاصيل الكاملة في **[TRACKING.md](TRACKING.md)**.

## التصميم
مبني على هوية MKN (ملفات الهوية الثلاثة) بطريقة إبداعية لا حرفية:
- **الزجاج (Glassmorphism):** شريط تنقل زجاجي عائم، وبطاقات زجاجية بإضاءة تتبع المؤشر، وبطاقات زجاجية فوق صور الحملات.
- **الانتشار (Diffusion):** خلفيات أُنتجت خصيصًا بروح موجة الهوية (من الداكن إلى الأزرق السماوي) في `assets/img/brand/`.
- **خطوط البناء:** خطوط هندسية مستوحاة من شبكة الشعار خلف الأقسام.
- **الختم الدائري:** «MKN ARABIA · MARKETING AGENCY» يدور حول شعار MKN في التذييل.
- **الشعار بخط عربي:** «سوّق بالعربي، سوّق صح» بخط Aref Ruqaa، و«BUILD. SCALE. GROW.» بخط Manrope.
- **الضوء العمودي:** خلفية الدعوة الختامية «النمو يُبنى، لا يُطارَد» من مشهد الضوء في الهوية.
- **شخصية العلامة:** مؤشرات النبرة (جاد/مرح، عصري/تقليدي…) في صفحة «من نحن».

## التعديل
- **رابط حجز الاستشارة (Google Calendar)**: `BOOK` و `BOOK_EMBED` في أعلى مولّد الصفحات؛ ويظهر الحجز المضمّن في `contact.html#book`.
- **رقم واتساب والبريد**: أعلى `assets/js/main.js`.
- **الألوان**: متغيرات `:root` في `assets/css/style.css` (الأسود `#0d1114` والأزرق `#3fb3dc` من البروفايل).
- **الشعار**: `assets/img/logo-white.png` و `logo-dark.png` (من ملفات الهوية الأصلية).
- **صور الأعمال**: `assets/img/work/`.

## ملاحظات تقنية
- روابط CSS/JS تحمل `?v=` يتغير تلقائيًا مع كل تعديل، فيحصل الزوار دائمًا على أحدث تصميم رغم التخزين المؤقت الطويل.
- صفحة `404.html` تستخدم روابط تبدأ بـ `/` لتعمل في أي مسار.
- `sitemap.xml` يُحدَّث مع كل بناء للموقع.

## النشر على Hostinger (mknarabia.com)
**الطريقة الأسهل — Git من لوحة Hostinger:**
1. ادمج طلب الدمج في الفرع الرئيسي على GitHub.
2. hPanel ← Websites ← mknarabia.com ← Advanced ← **Git**.
3. Repository: `https://github.com/noorabuallan/testing.git` — Branch: `master` — Directory: اتركه فارغًا (`public_html`).
4. اضغط Deploy، وفعّل Auto Deployment ليتحدث الموقع مع كل تعديل.

**أو يدويًا:** File Manager ← `public_html` ← ارفع كل الملفات والمجلدات (`index.html` وبقية الصفحات، `assets/`، `insights/`، `.htaccess`، `robots.txt`، `sitemap.xml`).

بعد النشر: فعّل SSL المجاني من hPanel ← Security ← SSL. ملف `.htaccess` يحوّل كل الزيارات إلى `https://mknarabia.com` ويفعّل الضغط والتخزين المؤقت.
