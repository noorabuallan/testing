# موقع MKN Arabia

موقع تعريفي ثابت (HTML/CSS/JS) باللغة العربية لوكالة MKN Arabia — بدون أي مكتبات أو خطوات بناء.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `services.html` | الخدمات + الباقات |
| `work.html` | العملاء حسب الدولة |
| `about.html` | من نحن، القيم، المؤسس والفريق |
| `contact.html` | نموذج تواصل (يُرسل عبر واتساب) + الأسئلة الشائعة |
| `404.html` | صفحة غير موجودة |

## ما يجب تعديله قبل النشر
1. **رقم واتساب والبريد**: في أعلى `assets/js/main.js` (`WHATSAPP_NUMBER` و `EMAIL`).
2. **روابط السوشال ميديا**: ابحث عن `href="#" aria-label="Instagram"` وغيرها في الصفحات.
3. **الألوان**: من متغيرات `:root` في `assets/css/style.css`.
4. **أدوار أعضاء الفريق**: في `about.html` (حالياً "فريق MKN").
5. **الشعار**: الشعار الحالي نصي مؤقت؛ استبدله بملف الشعار الرسمي في `assets/img/`.

## التشغيل محلياً
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر
يعمل مباشرة على GitHub Pages أو Netlify أو Vercel أو أي استضافة عادية (ارفع الملفات كما هي).
